## W3 T6 — 2^27 Stage5 scale fix — 2026-07-30

### Root cause and fix

- Metal-only 32-bit word-offset overflow in `crates/jolt-kernels/src/metal/shaders/instruction.metal`: the stage-5 instruction read+RAF cycle state contains `combined_val + 4 ra` tables, each with `2^27` field elements of 8 `uint` limbs. The fifth table starts at word `4 * 2^27 * 8 = 2^32`, so `uint` pointer math wrapped `ra[3]` onto `combined_val`; the init write and first cycle-round read both aliased.
