# Bounded terminal integer constraints

This is a partial acceptance-circuit component for the reviewed K16/D64 frozen
muldiv profile. It implements exact signed ranges, the **complete** terminal z
squared-L2 cap, and individual A and consistency integer rows over BN254. It
neither verifies an Akita proof nor authenticates the provided row routing.

## Integer argument

A signed value with public bound B is represented by a materialized field handle
x and byte-bit decompositions u and d. The constraints are `u+d=2B` and `x=u-B`.
Each byte is eight Boolean bits. For B<=i128::MAX, both decompositions use at most
128 bits, so `u+d<2^129<r`. Their equality is therefore an integer equality,
forcing u,d in [0,2B] and x in [-B,B]. Rounded byte allocation does not weaken the
exact interval. The zero bound works with zero bytes and equality rows.

`centered` takes an already canonical Fp128 handle a and constrains a Boolean
sign s plus `x=a-q*s`, with |x|<=(q-1)/2. The residual magnitude is below 2q<r.
Thus this binds the unique centered representative, including negative values;
it does not merely trust the sign or the host's supplied assignment.

For the norm, each x_i² is a multiplication row. An exactly bounded nonnegative
slack s in [0,C] satisfies `sum_i x_i²+s=C`. Before emission, public bounds must
satisfy `sum_i B_i²+C<r`; this is checked using BigUint and the actual BN254 scalar
modulus derived from its field encoding. The field equation then implies the
integer inequality. `TerminalZ` requires all 16,384 coordinates, uses B=23,377,
and C=546,507,225. The same private, immutable coordinate handles are consumed by
both row methods. There is no Linf-or-L2 branch.

For each generic row, declare fixed integer coefficients, bounded signed value
handles, optional products of two such handles, a positive source modulus q,
and a bounded quotient k. The code sums absolute term bounds to L, then requires
`L+q*K<r` in release before emitting any product or row gates. Equality
`sum terms=q*k` modulo r consequently is integer equality. The quotient's bound
is exact, not rounded to its magnitude bit count. A zero coefficient may ignore
a product semantically; this does not invalidate the absolute residual bound.

The concrete A caller uses all z coordinates once and |A_i|<=Q=(q-1)/2. Its
caller supplies the authenticated negacyclic coefficient permutation. The
consistency caller itself indexes z[64*p+j] and multiplies by 256 centered
weight handles. Both accept 294 pre-routed RHS handles with signed magnitudes
one or two and total absolute coefficient mass 371. These shape/mass checks
support the conservative bound; they do not establish canonical sparse sampling
or routing. Conservative exact quotient bounds remain K_A=191,504,570 and
K_consistency=2,992,442. Norm-aware improvements are intentionally not used.

## Circuit contract and omissions

ONE must be fixed by the outer statement. Handles have the existing same-builder
precondition; index checks catch unavailable coordinates, not coincident indices
from another builder. Known and unknown assignments emit identical matrices.
Invalid public bounds, no-wrap certificates, shapes and indices return typed
errors. Host assignment generation also rejects out-of-range values; soundness
comes from the independent range and relation constraints. Construction errors
after earlier successful allocations do not roll the builder back.

The profile is a fixed supported circuit shape, not an authenticated schedule
selector. Callers still must bind setup identity and A, derive weights from the
transcript point, bind decoded z/e/t to proof bytes, constrain sparse positions,
signs and negacyclic routing, check the scalar opening, and verify all preceding
Jolt/Akita checks. Passing these row methods cannot imply proof acceptance.
Private integers, signs, slack and quotient can be hidden by an eventual outer
ZK SNARK; this module supplies no ZK proof and no constant-time witness generator.

## Validation and diagnostic

Tests include an exact-range attack that changes every relevant bit and signed
handle consistently but violates the complement bound; sign and negative-wrap
mutations; a complete vector whose coordinates remain in range but whose sum of
squares exceeds the cap; an independent signed product equation; altered
quotients; deliberate +r and -r native-field aliases rejected by the release
bound guard; known/unknown matrix equality; and malformed terminal geometry.

The intentional example `terminal_r1cs_cost` reads trusted local census JSON,
uses its independently reviewed quotients, and checks one actual A row and one
actual consistency row with the complete z norm and canonical field bindings.
It allocates only the e/t coefficients used by those two rows. It is not an
untrusted artifact importer, does not authenticate JSON/proof/source hashes,
and does not replay the complete verifier. Counts include all allocated input,
range, centering, slack, quotient and product constraints. They are neither full
terminal costs nor proof-time/gas measurements.

Actual diagnostic result on the frozen artifact: **917,388 rows, 898,467
variables including ONE, and 4,188,238 nonzeros**. The completed assignment
satisfies every row. This includes only A coefficient row 0 and consistency
coefficient row 0, not the full 192+64 rows. No extrapolated total is reported.
